06 QAT 量化感知训练

QAT 的核心思想

核心洞察：QAT（Quantization Aware Training）在训练过程中模拟量化误差，让模型参数"学会"适应量化带来的精度损失。与 PTQ（训练后量化）的根本区别：PTQ 是"先训练再压缩"，QAT 是"带着压缩训练"。

原理展开：QAT 的核心思想可以用数学形式化表达。设原始参数为 W，量化函数为 Q(W)，QAT 的训练目标为：

W* = argmin_W L(f(x; Q(W)), y)

其中 L 是损失函数，f(x; Q(W)) 是使用伪量化权重的模型输出。与之对比，PTQ 的目标是找到最优量化参数 (s, z) 使得 ||W - Q(W)||² 最小——这是一个后处理优化问题。QAT 的优势在于它直接在量化约束下优化模型，参数会主动避开量化误差敏感区域。

QAT 在训练过程中模拟量化误差，让模型学会适应量化带来的精度损失。PTQ 是"训练后压缩"，QAT 是"带着压缩训练"。

💡 实用技巧：QAT 不需要从头训练！通常做法：先加载 PTQ 量化后的模型作为初始化，再用 QAT 微调 1-3 个 epoch。这样训练成本仅为从头训练的 1/10，但精度提升 1-3%。
⚠️ 注意事项：QAT 在 4-bit 及以上位宽时收益有限（仅比 PTQ 高 0.5%），但在 2-3bit 时优势明显（比 PTQ 高 3-5%）。不要在 4-bit 场景盲目使用 QAT——PTQ 的性价比更高。

Fake Quantization 原理

核心洞察：Fake Quantization 是 QAT 的核心操作——在训练的前向传播中模拟"量化→反量化"过程，使模型在训练阶段就"感受"到量化噪声，但反向传播仍使用 FP32 精度更新权重。

原理展开：Fake Quantization 的数学表达：

x_fake = (clamp(round(x/s) + z, 0, 2^b-1) - z) × s

其中 s 是 scale（量化步长），z 是 zero_point（零点偏移），b 是位宽。对于对称量化（z=0），s = max(|x|) / (2^(b-1) - 1)。例如：当 b=4，权重范围 [-2.5, 2.5] 时，s = 2.5/7 ≈ 0.357，每个量化步长代表 0.357 的数值变化。

QAT 的 Fake Quantization： 前向传播： W_real (FP32) → quantize → W_fake (INT4) → dequantize → W_dequant (FP32) output = input × W_dequant ← 用"伪量化"权重计算，模拟真实量化效果 反向传播： W_real 的梯度通过 STE (Straight-Through Estimator) 传递 grad_W ≈ grad_output × input ← 忽略量化操作的不可导性 优化器更新 W_real → 下一轮继续 fake quant
⚠️ 常见误区：Fake Quantization 不等于真正量化

初学者常误以为 Fake Quantization 阶段的量化参数（scale/zero_point）是固定不变的。实际上，每轮前向传播都需要根据当前权重的分布重新计算量化参数，因为权重在持续更新。如果沿用上一轮的 scale，会导致量化范围不匹配，引入额外截断误差。另一个误区是认为 fake quant 的精度损失可以忽略——在 2-bit 或 3-bit 场景下，STE 的梯度近似误差会显著累积，这也是 QAT 在极低位宽下仍需大量训练轮次的原因。

STE (Straight-Through Estimator)

核心洞察：量化函数中的 round 操作梯度为 0，如果直接反向传播梯度将全部消失。STE 的做法是：前向传播使用量化后的值，反向传播时假设量化函数的梯度为 1，直接将梯度传递给输入。

原理展开：STE 的数学表达：

前向: y = q(x) = round(x/s) · s 反向: ∂L/∂x ≈ ∂L/∂y · 𝟙[|x/s - round(x/s)| ≤ 0.5]

STE 的本质是用一个"光滑近似"替代不可导的量化函数。虽然数学上不精确（梯度是有偏的），但实践中效果很好——因为 STE 实际上是在优化一个光滑近似问题。数值实验表明：STE 的梯度估计与精确梯度的余弦相似度 > 0.95。

💡 实用技巧：STE 的梯度估计质量与量化位宽有关。4-bit 时余弦相似度约 0.95，2-bit 时降至 0.85。这就是为什么 QAT 在低位宽下需要更多训练轮次——梯度噪声更大。
量化函数 q(x) = round(x/s) · s 是不可导的（round 操作梯度为 0）

STE 的做法：前向用量化值，反向直接传梯度
∂L/∂x ≈ ∂L/∂q ← 假设量化函数的梯度为 1

QAT 训练代码

核心洞察：QAT 的工程实现核心是自定义 autograd.Function——forward 执行量化-反量化流水线，backward 使用 STE 直接传梯度。关键是每轮前向传播都需根据当前权重分布重新计算 scale/zero_point。

import torch
import torch.nn as nn

class FakeQuantize(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, scale, zero_point, bits):
        q_max = 2**bits - 1
        x_q = torch.clamp(torch.round(x / scale) + zero_point, 0, q_max)
        x_dq = (x_q - zero_point) * scale
        return x_dq

    @staticmethod
    def backward(ctx, grad_output):
        return grad_output, None, None, None  # STE: 直接传梯度

class QATLinear(nn.Module):
    def __init__(self, in_features, out_features, bits=4):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.bits = bits
        self.register_buffer('scale', torch.tensor(1.0))
        self.register_buffer('zero_point', torch.tensor(0))

    def forward(self, x):
        # 动态计算 scale/zero_point
        w = self.linear.weight
        q_max = 2**self.bits - 1
        self.scale = (w.max() - w.min()) / q_max
        self.zero_point = torch.round(-w.min() / self.scale)

        # Fake quantize 权重
        w_q = FakeQuantize.apply(w, self.scale, self.zero_point, self.bits)

        return torch.nn.functional.linear(x, w_q, self.linear.bias)

QAT vs PTQ 精度对比

核心洞察：QAT 的优势随位宽降低而增大。4-bit 时 QAT 仅比 PTQ 高 ~0.5%，但 2-bit 时高出 4-5%。选择策略：4-bit 用 PTQ（性价比更高），2-3bit 用 QAT（精度优势明显）。

方法4-bit3-bit2-bit
PTQ (GPTQ)~99%~96%~88%
PTQ (AWQ)~99%~97%~89%
QAT~99.5%~98%~93%
FP16 基线100%100%100%

注：百分比为相对于 FP16 基线的 MMLU 准确率保留比例

⚠️ 常见误区：QAT 一定比 PTQ 精度更高

虽然 QAT 通常在极低位宽（2-3bit）下优于 PTQ，但在 4-bit 及以上精度时，GPTQ/AWQ 等 PTQ 方法的精度已经非常接近 QAT，而训练成本仅为 QAT 的 1/100。QAT 的真正价值在于：1) 需要低于 4-bit 的极端压缩时；2) 目标模型有充足的训练数据和 GPU 预算时。对于大多数 4-bit 部署场景，PTQ 是性价比更高的选择——这也是为什么 GPTQ/AWQ 在工业界比 QAT 更常用。

QuIP#（2-bit 格量化）

核心洞察：QuIP# 实现了 2-bit 量化下接近 FP16 的精度（70B 模型 MMLU 75% vs FP16 的 79%），核心创新是两步策略：先通过随机正交旋转使权重分布更均匀（incoherent processing），再用 E8 格点编码实现最优量化。

量化分析：QuIP# 的实测数据：

模型FP16 MMLUQuIP# 2-bit MMLU精度保留显存 (FP16→2bit)
Llama-2-70B69.9%66.1%94.6%140GB → 18GB
Llama-2-13B55.6%52.8%95.0%26GB → 3.5GB
QuIP# 两步策略： 1. 随机正交旋转：W' = Q · W · R Q, R 是随机正交矩阵 效果：权重分布更均匀（incoherent processing） 量化误差更小 2. E8 格量化： 用 8 维格点编码 2-bit 值 每个格点覆盖一个区域 最近邻查找 → 量化值 精度：70B 模型 2-bit，MMLU 约 75%（vs FP16 的 79%）

AQLM（加性量化）

核心洞察：AQLM（Additive Quantization of Language Models）使用多个码本的组合来表示权重，实现极低比特率（1-2 bit）。核心思想：将权重分解为多个低精度码本条目的和。

原理展开：AQLM 的数学表达：

w ≈ Σᵢ₌₁ᘦ c_{jᵢ}，其中 c_{jᵢ} 从码本 Cᵢ 中选择

M=2 个码本，每个 2^15 个条目 → 选择 2 个索引（各 15 bit）表示一个权重 → 等效约 1.58 bit/参数（考虑码本共享）。AQLM 的优势是 PTQ 方法，不需要训练，但压缩率接近 QAT。

BitNet b1.58（1.58-bit）

核心洞察：BitNet b1.58 使用三值权重 {-1, 0, 1}（1.58 bit = log₂(3)），将乘法运算转化为加法/符号翻转，理论上可将芯片功耗降低 10x+。但需要从头训练，不能通过 PTQ 应用到已有模型。
